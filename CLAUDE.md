# CLAUDE.md

CS541 group project: golf ball object detection (and, with the `golf-ball` dataset, new vs. old/defective ball classification). Four-person team; no model/training code yet — the repo currently holds datasets and data tooling only.

## Setup

- Python >=3.12, managed with **uv**. Use `uv sync`, `uv add <pkg>` (never pip), `uv run scripts/<script>.py`.
- Only dependency so far: Pillow.

## Layout

- `data/raw/` — imported sources (NDJSON + the Roboflow originals). `data/cropped/` — generated by `scripts/crop_dataset.py`, committed on purpose because the CDN URLs expire.
- `scripts/` — all tooling; `common.py` holds the shared paths (`RAW`, `CROPPED`) and `load_ndjson`/`open_image`, so scripts run from any directory.
- `docs/` — assignment PDF and the LaTeX paper example.

## Data (`data/raw/`)

All datasets share one NDJSON format (Ultralytics style):
- Line 1: `{"type":"dataset","task":"detect","class_names":{"0":...},...}`
- Line 2+: `{"type":"image","file":...,"url":...,"width":W,"height":H,"split":"train|val|test","annotations":{"boxes":[[cls,xc,yc,w,h],...]}}` — boxes are **normalized 0–1**, center-format (YOLO).

| File | Images | Classes | Images located |
|---|---|---|---|
| `golf-ball-roboflow.ndjson` | 2188 | `Golf-ball` | local, under `data/raw/golf-ball-roboflow-original/{train,valid,test}` (`file` is relative to the NDJSON's folder, `data/raw/`) |
| `golf-ball-detection.ndjson` | 989 | `Golf-ball` | only via signed `url` (Ultralytics CDN, expires) |
| `golf-ball.ndjson` | 60 | `New golf`, `old  golf` (note double space) | only via signed `url` (expires); has defect examples |

- **Never delete `data/raw/golf-ball-roboflow-original/`** — `golf-ball-roboflow.ndjson` points into it.
- Only `golf-ball.ndjson` contains defective/old balls; the other two have none.
- Class IDs differ between datasets (1 class vs. 2) — check each header's `class_names` before merging.

### Cropped copies

`data/cropped/<name>.ndjson` + `data/cropped/<name>/<split>/<orig>_<box index>.jpg` for each dataset above. One crop per bounding box (multi-ball images yield several). All images are **128×128** (`OUT_SIZE`): box expanded to a square around its center (shifted inside the image, capped at the image's short side), cropped, converted to grayscale (mode `L`), Lanczos-resized. Boxes under 32 px on the shorter side (`MIN_SIZE`, original pixels) are dropped; images with no boxes yield nothing. Each record's box is that ball's location inside the crop; other balls in the window are unlabeled. Crops are local, so they don't depend on expiring URLs. Regenerate with `uv run scripts/crop_dataset.py [name ...]` (the detection and golf-ball sources need valid CDN URLs).

## Scripts

- `scripts/coco_to_ndjson.py` — converts the Roboflow COCO export (`*/_annotations.coco.json`) to `golf-ball-roboflow.ndjson` (clamps boxes to image bounds, drops empty ones). Run: `uv run scripts/coco_to_ndjson.py`.
- `scripts/crop_dataset.py` — builds the cropped datasets above; optional args limit it to named datasets (e.g. `golf-ball`). Records without `annotations` count as zero boxes.
- `scripts/preview_image.py` — draws boxes on one image. `uv run scripts/preview_image.py data/raw/<file>.ndjson [index|name-substring] [--save out.png]`; random image if no selector. Prefers the local file, falls back to the URL.

# CLAUDE.md

CS541 group project: golf ball defect detection with an autoencoder trained on normal balls (high reconstruction error = damaged ball). All three datasets are normal balls; there is no defect test data yet. Four-person team; no model/training code yet — the repo holds datasets, data tooling and the data loader (`scripts/golf_dataset.py`).

## Setup

- Python >=3.12, managed with **uv**. Use `uv sync`, `uv add <pkg>` (never pip), `uv run scripts/<script>.py`.
- Dependencies: Pillow, numpy, torch.

## Layout

- `data/raw/` — imported sources (NDJSON + the full-size images of all three datasets in `<name>-original/`). `data/cropped/` — generated by `scripts/crop_dataset.py`.
- `scripts/` — all tooling; `common.py` holds the shared paths (`RAW`, `CROPPED`), `load_ndjson`/`open_image` and `circle_mask`, so scripts run from any directory.
- `docs/` — assignment PDF and the LaTeX paper example.

## Data (`data/raw/`)

All datasets share one NDJSON format (Ultralytics style):
- Line 1: `{"type":"dataset","task":"detect","class_names":{"0":...},...}`
- Line 2+: `{"type":"image","file":...,"url":...,"width":W,"height":H,"split":"train|val|test","annotations":{"boxes":[[cls,xc,yc,w,h],...]}}` — boxes are **normalized 0–1**, center-format (YOLO).

| File | Images | Classes | Images located |
|---|---|---|---|
| `golf-ball-roboflow.ndjson` | 2188 | `Golf-ball` | local, under `data/raw/golf-ball-roboflow-original/{train,valid,test}` (`file` is relative to the NDJSON's folder, `data/raw/`) |
| `golf-ball-detection.ndjson` | 989 | `Golf-ball` | local, under `data/raw/golf-ball-detection-original/{train,val,test}` (downloaded; signed `url` kept but expires) |
| `golf-ball.ndjson` | 60 | `New golf`, `old  golf` (note double space) | local, under `data/raw/golf-ball-original/{train,val,test}` (downloaded; `url` kept but expires) |

- **Never delete the `*-original/` folders** — the NDJSONs point into them (Roboflow's can't be re-downloaded by script; the other two can only until their URLs expire).
- All three datasets are normal balls; none has defects, despite `golf-ball.ndjson` having `New golf`/`old  golf` classes.
- Class IDs differ between datasets (1 class vs. 2) — check each header's `class_names` before merging.

### Cropped copies

`data/cropped/<name>.ndjson` + `data/cropped/<name>/<split>/<orig>_<box index>.jpg` for each dataset above. One crop per bounding box (multi-ball images yield several). All images are **128×128** (`OUT_SIZE`): box expanded to a square around its center (shifted inside the image, capped at the image's short side), cropped, converted to grayscale (mode `L`), Lanczos-resized, then everything outside the ball's circle (`circle_mask`: centered on the box, diameter = mean of box w/h) is set to black. Boxes under 32 px on the shorter side (`MIN_SIZE`, original pixels) are dropped; images with no boxes yield nothing. Each record's box is that ball's location inside the crop; other balls in the window are unlabeled. Regenerate with `uv run scripts/crop_dataset.py [name ...]` (reads the local raw images); `--remask [name ...]` re-applies the circular mask to existing crops in place.

## Scripts

- `scripts/coco_to_ndjson.py` — converts the Roboflow COCO export (`*/_annotations.coco.json`) to `golf-ball-roboflow.ndjson` (clamps boxes to image bounds, drops empty ones). Run: `uv run scripts/coco_to_ndjson.py`.
- `scripts/crop_dataset.py` — builds the cropped datasets above (circular-masked); optional args limit it to named datasets (e.g. `golf-ball`); `--remask` masks existing crops in place. Records without `annotations` count as zero boxes.
- `scripts/download_images.py` — downloads the Ultralytics-hosted images (`golf-ball-detection`, `golf-ball`) into `data/raw/<name>-original/<split>/` and rewrites each record's `file` to the local path. Run: `uv run scripts/download_images.py [name ...]`.
- `scripts/golf_dataset.py` — autoencoder data loader over all three cropped datasets: `golf_balls(split)` / `loader(split)` yield `(img, mask)` `[1,128,128]` (image black outside the circle; compute loss only where mask is 1). Train split gets flips + brightness augmentation. `uv run scripts/golf_dataset.py` runs a self-check.
- `scripts/preview_image.py` — draws boxes on one image. `uv run scripts/preview_image.py data/raw/<file>.ndjson [index|name-substring] [--save out.png]`; random image if no selector. Prefers the local file, falls back to the URL.
